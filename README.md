# SENTINEL-RAG

SENTINEL-RAG is a production-oriented closed-loop Retrieval-Augmented Generation (RAG) system.

## Project Objective

The central concept of SENTINEL-RAG is an **Evidence Orchestration Policy** that dynamically controls retrieval, evidence assessment, verification, repair, and abstention under explicit quality, latency, and cost constraints.

## Tech Stack (Planned)

* **Backend:** Python + FastAPI
* **Database:** PostgreSQL
* **Vector Search:** pgvector
* **Lexical Retrieval:** BM25
* **Cache:** Redis
* **Frontend:** Next.js + TypeScript
* **Containerization:** Docker + Docker Compose
* **Evaluation:** Python-based benchmark/evaluation framework
